# 分享歌曲 0.4.1

QQ 音乐改用自己的会员账号授权取链，不再使用已失效的公共试听地址。保留已有的歌曲卡片、专辑封面、卡片配色、角色发歌工具及 Apple Music / 网易云选项。

## QQ 音乐设置

先更新自己的 Vercel 音乐服务到 0.3.0，配置 `QQ_SESSION_SECRET`，然后在插件的 **设置 → QQ 音乐账号** 保存服务地址和原有 `MUSIC_ACCESS_KEY` 服务口令。选择开通会员时使用的 **QQ** 或 **微信** 扫码并确认。无需提供密码或手工粘贴 Cookie。

手机可保存二维码，在相应 App 的扫一扫中从相册选取；也可使用另一台设备显示二维码。授权完成后自动选择 QQ 音源。发现页和聊天里的歌曲卡片使用同一个播放器，支持暂停、上一首、下一首和进度。

详细部署步骤：[音乐服务说明](../music-service/README.md)。

## 播放范围

- QQ：需要在本插件单独登录。会员账号的实际权限、歌曲及部署网络决定能否获取完整音频。不保证每首歌成功。取不到整曲时显示错误，不自动换歌或切为试听，不解密 DRM 音频。
- Apple Music：仍为官方试听片段和 App 跳转，本版没有接入 MusicKit 账号授权。
- 网易云：原有自建服务配置和旧卡片保持兼容。

账号加密会话只保存在本机插件配置，发往自己配置的音乐服务。卡片、角色上下文和公开 GitHub 文件不含登录会话或服务口令。更换服务地址会清除旧会话。退出登录清除本机 token，已签发的 sealed token 无法立即由服务端撤销。

## 验证情况

2026-11-12 实测 QQ 扫码二维码可创建，状态返回等待扫码，匿名搜索返回正确歌曲 MID、媒体 MID 和专辑信息。24 项账号契约及 WebKit 测试、28 项多音源测试、35 项聊天/层级检查及移动端布局检查通过。Chrome 测试解码 WAV 样本，Windows WebKit 的音频行为使用模拟对象。

**尚未登录用户会员账号，会员整曲播放需要用户扫码后验证。** 未在 iPhone 真机验证；浏览器若阻止播放，可再次点播放，保留已解析的音频而不重新取链。

## 安装与回退

[当前安装文件](./plugin.json) 或已安装插件中的检查更新，之后刷新 Roche。旧卡片和角色开关无需重建；QQ 账号只需首次授权。

脚本固定版本路径 `releases/0.4.1/roche-song-share.js`。旧版安装入口：[0.4.0](./releases/0.4.0/plugin.json)。旧版公共 QQ 音源目前失效，回退不会恢复该音源。
