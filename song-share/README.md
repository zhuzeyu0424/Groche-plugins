# 分享歌曲 0.5.1

采用已选定的第一种紧凑横卡。编辑入口改为平台名称旁的小铅笔，平时隐藏；点一下封面、歌名或卡片空白处显示，再点小铅笔可修改附言或原位换歌。点卡片其他位置可收起，点卡片外也会收起。同一时间只显示一张卡片的编辑入口。

播放键保持直接播放，平台名称保持打开原平台。键盘可聚焦卡片后按回车或空格显示编辑，按 Escape 收起。不新增底部按钮行，编辑入口显隐不改变卡片大小；有附言才显示附言区域。保留原有专辑封面、双方配色、歌曲信息与播放状态。

保留 0.5.0 的原位编辑、换歌和完整歌曲文字块自动恢复。修改仍保留发送人、发送时间及聊天位置，遇到并发修改时停止覆盖。不会因点按卡片额外调用聊天或音乐 API。

## 更新

检查更新到 0.5.1，然后刷新 Roche。已有卡片会使用新外观，无需重发，不需要重新登录 QQ。音乐服务保持 0.3.3，服务地址、口令、环境变量与账号会话无需变更。

QQ 播放受账号、歌曲和网络权限影响；Apple Music 仍是试听和 App 跳转。

[安装文件](./plugin.json)。脚本固定在 `releases/0.5.1/roche-song-share.js`；[0.5.0 回退入口](./releases/0.5.0/plugin.json)。
