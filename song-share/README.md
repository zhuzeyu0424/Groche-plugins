# 分享歌曲 0.4.0

在 Roche 内搜索、互相分享歌曲，并播放音源实际提供的音频。延续瓷白界面、专辑封面、分双方设置的卡片配色、圆润 SVG 按钮和顶层弹窗。

- Apple Music：默认音源，页面内播放官方试听片段。点歌曲下方的平台文字可打开 Apple Music 完整收听；插件内没有接入 MusicKit 账号授权，拥有 Apple Music 会员不会自动解锁插件里的整曲播放。
- QQ 音乐：在发现页音源下拉框选择。使用落月公开接口 `https://api.vkeys.cn/v2/music/tencent` 搜索并解析音频，不使用其他插件作者的服务器或账号。播放能否成功、是整曲还是试听，取决于接口当前返回的内容；明确显示试听标记，不解密受保护音频，不自动换成其他歌曲。
- 网易云音乐：保留既有自有服务配置和旧卡片播放，使用原服务口令。口令仅发往用户配置的服务，不发送给 QQ 或 Apple。
- 播放器：页面底部固定显示，播放/暂停、上一首/下一首、进度调节；关闭插件页面后保留当前音频，停用/重载插件会释放播放器。
- 分享：原有角色工具、去重、聊天隔离和卡片数据保持兼容。搜索和分享不会自动播放。

本版独立实现音源适配，没有复制其他播放器的源码或 UI。参考项目的作用是确认音源和播放方式的差别。

## 当前验证

2026-11-12：Apple《Baby (feat. Ludacris)》真实跨域搜索及 30 秒音频解码成功，进度推进。Chrome 模拟音源测试覆盖实际 WAV 解码，WebKit 测试使用模拟 Audio（Windows 测试环境缺解码能力），另完成 WebKit 分享/层级/移动布局检查。未在用户 iPhone 真机上验证，iOS 若阻止自动播放需再次点播放。

同日抽测 QQ《Baby》《Yellow》《知足》：搜索接口返回 200，解析标记“音乐试听”，但返回音频的 HTTP 和 HTTPS 请求为 404。此结果说明该公开音源当时不可用，不能宣称接入后所有歌曲均能播放。QQ 音源保留为可选；默认 Apple。

## 安装与回退

安装 `song-share/plugin.json`，或者在已安装插件中检查更新；随后刷新 Roche。发现页可选音源。数据和角色开关无需重新配置。

当前脚本固定在 `song-share/releases/0.4.0/roche-song-share.js`，避免旧 manifest 指向后续变更的脚本。旧版安装地址为 `song-share/releases/0.3.2/plugin.json`。

本地回归：`test-layer.cjs`、`test-multisource.cjs`、`test-design.cjs`。联网验证：`check-online-playback.cjs --apple`。
