# 分享歌曲 · Roche 插件

版本：0.1.3

安装链接：

https://raw.githubusercontent.com/zhuzeyu0424/roche-plugins/main/song-share/plugin.json

在 Roche「插件 App 管理」粘贴以上完整链接安装。已安装旧版的用户也请使用这个链接安装，以便后续从 GitHub 检查更新，无需先卸载。

## 使用

1. 在聊天的加号菜单打开「分享歌曲」，确认当前聊天对象。
2. 搜索歌名或歌手，选择歌曲，加上可选附言后发到聊天。
3. QQ 音乐、网易云和 Apple Music 的分享链接可以在「粘贴链接」中添加；需要自己填写歌名，可选填写歌手。
4. 开启当前聊天的「允许他在聊天时分享歌曲」后，角色可以在回复时搜索并发送歌曲卡片。角色使用 Roche 原生工具调用，需要当前 Roche 版本及聊天模型支持。
5. 点击卡片前往音乐平台收听。是否能播放完整歌曲取决于平台、地区及账号权限。

## 当前范围

- 内置搜索使用 Apple 公开曲库；没有接入 QQ 或网易云的站内搜索。
- 角色读取歌名、歌手和附言，不会直接听取音频或读取歌词。
- 角色主动分享支持线上单人聊天，需要分别为每个聊天开启。
- 每轮最多发送一张角色歌曲卡片；非明确索歌时，两次主动分享至少间隔 15 分钟。
- 「我们的歌」展示当前聊天最近 100 条消息中的歌曲。
- 关闭 Roche 后，本插件不会后台运行或自动发歌。

## 存储与网络

插件文件由 GitHub 提供，歌曲搜索直接连接 itunes.apple.com，不需要 Supabase 或额外服务器。搜索会把输入的关键词发送给 Apple。歌曲封面仅允许 Apple 图片域名；不会把聊天记录发送到搜索服务。

开关按聊天保存在当前浏览器；歌曲卡片由 Roche 保存。打开歌曲链接会跳转到相应平台。搜索失败不会自动重试，也不会自行调用额外聊天模型；角色使用工具产生的正常聊天费用仍按你的聊天接口计费。

如安装出现 Load failed，先确认手机网络能够访问 raw.githubusercontent.com。插件下载和曲库搜索是两个不同的网络连接，任一不可达都会影响对应功能。

## 验证范围

已提供 WebKit 模拟 Roche 接口验证及公开下载检查。真实手机上的 Roche 版本、模型工具调用能力和网络条件仍需实际使用确认。

## 0.1.2 修复

角色发歌改用一次 send_song 调用完成搜索、核对及发送，适配每轮仅执行一次插件工具的 Roche。不会把搜索到的任意第一首歌直接发送；未匹配歌名或歌手时返回明确原因。

开启分享后仍无卡片，可重新打开插件，展开「角色发歌状态」查看本次打开期间的最后一次调用。没有调用记录表示尚未收到工具执行请求，不能仅凭角色的文字判断搜索服务失败。刷新会清除这条诊断，已保存的开关和卡片不受影响。

## 0.1.3 修复

移除会让 iPhone 搜索跳转到音乐 App 的 media=music 参数，保留 entity=song 筛选歌曲。手机和角色发歌共用此修复，不增加代理、服务器或自动重试。已用 iPhone Safari User-Agent 的 WebKit 验证真实搜索与一次调用发送测试卡片；仍需手机实际网络下使用确认。
