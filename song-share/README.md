# 分享歌曲 0.4.2

修复登录 QQ 后搜索容易返回空列表的问题：关键词搜索固定使用公开曲库，播放继续使用已授权的会员账号。搜索歌手名会列出相关歌曲，无需先填写具体歌名。原有登录、歌曲卡片、封面、卡片配色和角色发歌设置保持兼容。

## 已配置用户如何更新

更新插件到 0.4.2 并刷新 Roche。音乐服务更新到 0.3.1 后，服务端同样保证搜索不携带 QQ 会话。已保存的服务地址、口令、QQ 登录与 `QQ_SESSION_SECRET` 无需更换。公开搜索无结果时显示 QQ 专用提示；搜索格式异常会报错，不再显示成“没有找到”。

## 首次配置

自己的 Vercel 音乐服务需要 `MUSIC_ACCESS_KEY` 和至少 32 位随机字符的 `QQ_SESSION_SECRET`。插件 **设置 → QQ 音乐账号** 中：

- 音乐服务：自己的 Vercel 服务首页地址，例如 `https://groche-plugins-music-service.vercel.app`。
- 服务口令：Vercel 中原有的 `MUSIC_ACCESS_KEY` 值，不是 `QQ_SESSION_SECRET`，也不是 QQ 密码。
- 保存并连接后，用开通会员时的 QQ 或微信账号扫码并确认。

[音乐服务部署说明](../music-service/README.md)。

## 播放和账号

QQ 播放依赖会员账号的实际权限、歌曲及部署网络，不保证每首歌成功。取不到整曲时显示错误，不自动换歌或切为试听，不解密 DRM 音频。Apple Music 仍是官方试听和 App 跳转；网易云沿用原自建服务。

账号加密会话保存在本机插件配置，仅发往自己配置的音乐服务，公开搜索不会携带 QQ 会话。卡片、角色上下文和 GitHub 文件不包含登录 token 或服务口令。更换服务地址会清除旧会话；退出登录清除本机 token。已签发的 sealed token 无法立即由服务端撤销。
