# 分享歌曲 0.3.0

简洁浅色首页，自动加载 Apple 曲库歌曲及专辑封面；支持搜索、双方分享和五种聊天卡片配色。

安装：https://raw.githubusercontent.com/zhuzeyu0424/Groche-plugins/main/song-share/plugin.json

在设置中选择聊天并开启角色分享，分别选择双方卡片配色。新搜索默认使用 Apple 曲库，即使之前保存了网易云服务。点击 Apple Music 链接前往平台收听，当前不包含 MusicKit 站内完整播放。旧网易云卡片保持原平台及备用服务配置。

首页发现按日期轮换歌手，从公开曲库获取歌曲，不使用个人听歌记录，也不会自动发送消息。网络不可用时显示提示；封面由音乐平台提供，平台访问失败时仍可能无法显示。手动输入链接未包含封面时不伪造封面。

验证：33 项回归检查，首页加载、真实封面解码、无自动发消息、旧设置兼容、双方配色、SVG 控件，以及 320/390/430 宽度布局。真实 iPhone 跳转及账号播放需在设备验证。
