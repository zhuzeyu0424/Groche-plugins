# 分享歌曲 0.4.3

减少 QQ 搜索间歇失败对角色发歌的影响。已登录服务的公开搜索结果在本次打开中缓存 15 分钟；重复查询共用请求。你或角色刚搜到的歌曲，角色发歌时会先按准确歌名和歌手复用有效结果。不会自动换歌、切换平台或重试播放。

QQ 的公开搜索接口仍可能间歇拒绝请求。没有有效结果时不能保证发歌成功，搜索失败不会伪造卡片或声称发送成功。服务 0.3.2 会明确区分 QQ 搜索拒绝（例如 2001）和一般连接错误，拒绝不再统一显示为网络故障。

## 更新

更新插件并刷新 Roche。保留已有 QQ 登录、音乐服务地址、服务口令和角色分享开关，不需要重新扫码。缓存只有歌曲名称、歌手、封面及编号，不含会员会话；不会保存音频。刷新后缓存清空。

自己的 Vercel 项目会随 `music-service` 更新至 0.3.2，原有环境变量保持不变。[服务配置说明](../music-service/README.md)。

QQ 整曲取链继续使用用户授权的会员账号，受歌曲权限和服务网络影响。Apple Music 仍提供试听和 App 跳转，网易云配置保持兼容。
