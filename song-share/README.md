# 分享歌曲 0.5.0

支持在原卡片上编辑附言与换歌。点卡片右下角的“…”：直接改附言后保存，或点“换歌”搜索另一首，选择后保存。修改原消息，保留发送人、发送时间和聊天位置，不追加新消息，不调用聊天模型或自动播放。

## 编辑后卡片恢复

Roche 的整段编辑会把插件卡片重新解析为文字。本版在当前打开的私聊里识别完整的 `【分享歌曲】` 信息块，并通过已核验的 Roche 原生消息更新接口恢复卡片。歌名、平台、链接、附言和原有语义文字继续保存。截图这类完整歌曲块可以自动恢复；不要删掉或改坏歌曲链接。

只处理可见消息中独立、完整的歌曲块。不转换混在其他文字中的引用，不恢复已删除或撤回的消息，不修改记忆、其他插件消息或后台聊天。遇到未知的 Roche 更新接口时停止修改，避免误改数据。已核验 `ai-core-C0vFRHpB.js` 与 `ai-core-De7sMNqT.js` 中的原生消息更新函数。

近期歌曲封面和编号在本机保留最多 160 条小型元数据，不存音频。QQ 旧卡片没有封面时，通过自己的音乐服务公开查询歌曲详情；接口失败不自动重试，也不调用生图。

## 更新

更新插件并刷新 Roche，再打开对应聊天。保留已有登录、音乐服务、角色开关和卡片配色。自己的 Vercel 服务同步到 0.3.3，原有环境变量保持不变，无需重新扫码。

QQ 整曲播放受账号、歌曲和服务网络影响；Apple Music 仍提供试听和 App 跳转。本版没有接入 Apple Music 会员完整播放，也没有更改音源权限。

## 验证

WebKit 的恢复和编辑测试使用真实 Roche 更新函数与模拟存储，覆盖原位换歌、附言修改、并发修改保护、其他聊天隔离、撤回/删除保护和 320/390/430 像素布局；另通过原有账号、搜索缓存、聊天和播放回归检查。真实 QQ 公开查询已验证《春风吹》的歌曲编号、封面与媒体编号。未读取用户账号或聊天数据库，手机上的实际表现仍需用户试用。
