# 锁脸多图参考 0.6.1

[安装或更新](https://raw.githubusercontent.com/zhuzeyu0424/Groche-plugins/main/reference-images/plugin.json?v=0.6.1)

在 Roche 插件管理里用上面的链接覆盖更新。角色与人设的图片、造型预设和历史记录存放在原来的本机参考库，可直接继续使用。

## 群聊和角色相册

- 群聊按画面提示词里出镜的人物匹配参考。比如 Soap 发 Ghost 的照片时，画面描述里写 Ghost 的姓名、账号名或群昵称，使用 Ghost 保存的参考。
- 群聊旧图可以编辑提示词后重绘。插件读取这次重绘的画面描述。
- 角色相册整批生图和照片详情里的重绘都按该张照片的画面匹配。新生成的相册描述会尽量写清楚出镜角色。风景、物品和无法确认出镜人物的照片按原生场景生图。
- 已生成的照片会保留。要让一张旧图用新版规则，可打开该照片点重绘。一次相册整批生成仍会按 Roche 原有流程绘制多张照片。
- 打开「多图参考 → 生成记录」核对实际使用的角色和参考图张数。

## 参考设置

角色从「锁脸 → 多图参考」进入。我的参考在「人设库 → 编辑人设 → 人设描述」旁边。每人最多保存四张人物参考，单人使用全部已保存人物图，双人各优先使用两张主参考，可另带画风图。线上角色照、群聊及相册只给识别到的出镜人物加参考。线下对话可跟随当前聊天使用的人设。

前两张主参考可选同一外貌的正面和四分之三侧面。其余可用另一角度或半身照。固定外貌只写五官、肤色、发色、体型等稳定特征，服装、表情、镜头和灯光写在当次画面里。在单独的插件备份里导出参考设置和造型预设，可在换设备前保留这些内容。

## 验证和回退

已在隔离 WebKit 中用当前公开 Roche 代码验证群聊旧图编辑重绘、相册批量生成和单张重绘的请求。测试使用模拟绘图服务，提交了零笔真实生图请求。多图参考适用于本页兼容的 OAI 生图请求，实际画面由所用绘图模型生成。
