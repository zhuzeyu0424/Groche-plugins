# 分享视频 0.2.0

从 Roche 聊天中的「分享视频」选择或拍摄短视频。支持 30 秒以内、25 MB 以内、浏览器可解码的视频。Live Photo 请先在手机相册中存储为视频。

发送时沿用 Roche 的视觉模型或配置独立兼容接口；抽取 4 帧生成描述，没有声音识别，不自动重试。旧照片卡片仍可查看。

## 本机空间
展开「视频占用与清理」查看插件原片的数量与大小，勾选或按日期选中，确认后删除。统计为原片数据大小，不包含数据库开销，也不是 Roche 的总占用。
仅操作插件自己的媒体库，不删除聊天、封面、视觉描述或记忆。清理后原卡片不能播放；手机相册原片不受影响。
聊天卡片点击后才读取原片，没有自动清理。

## 备份
原片保存在当前浏览器的插件媒体库，Roche 普通备份不包含它。请保留手机原片；换设备、清空网站数据可能使原片不可用。
