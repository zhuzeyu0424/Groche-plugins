# 日常记忆精简 0.1.0

给 Roche 的事实记忆做小范围整理。可以本地筛出长记忆、新增或改动、疑似重复项，逐条改正文，也可以让独立文本模型起草。重复项只提示，不自动合并或删除。插件不删除聊天、线下归档或核心记忆。

## 安装和第一次使用

1. 在 Roche 的「插件 App 管理」添加本目录的 `plugin.json` 地址，安装后打开「日常记忆精简」。
2. 在「记忆」选择聊天。首次扫描可以点「记为已查看」，以后用「新增 / 改动」看变化。「编辑原文」可以直接修改草稿，不需要配置 API。
3. 需要 AI 帮写时，在「设置」填兼容 Chat Completions 的 API 地址、Key 和文本模型，保存。可以先「拉取」模型或手填。套餐、价格和实际兼容性以站点为准。
4. 建议先选一条，点「精简所选」。在「任务」检查原文和草稿，确认人物、时间、承诺、条件、结果没丢，再勾选草稿和确认框，点「应用所选」。应用后可在同一任务里撤销；若原记忆后来被改过，插件会拒绝覆盖。

## 调用与任务

- 开启插件、读取记忆、手动改草稿都不发生成请求。只在点击「精简所选」后发出一笔请求，每批最多 5 条，默认每天最多 5 笔、单次输出上限 1,600 token。请求只包含所选事实正文和相关字段，不发送整段聊天或整个记忆库。
- 失败和结果未知都计入尝试次数，不自动重试。重新打开看「任务」。如果刷新或离开后结果未知，先核对站点账单再确认状态。「停止等待」只能停止本机等待，服务端可能仍完成并计费。
- 次数和 token 参数不等于金额上限；账单以 API 服务为准。若该聊天开启了向量记忆，应用或撤销后，Roche 可能单独同步向量并调用自己的 API。插件会在写入前要求确认这项费用风险。
- 原文、草稿、进度和撤销副本保存在当前浏览器，最多保留 20 个任务。换设备或清理站点数据前，请用「导出任务与原文」另存副本；不要依赖 Roche 普通备份。移除本机任务也会移除该任务里的撤销副本。导出不包含 API Key。
- 本地筛选和预览使用字数。任务只显示接口有返回的用量，不把字数变化当成下一轮聊天节省的 token。实际节省取决于 Roche 之后有没有把这条事实装进上下文。
