# 微信多图收起 v0.1.0

配合本次微信 CSS 使用的独立 Roche 插件。没有聊天读写、AI 生成或第三方服务调用；只调整当前页面上已有图片消息的显示。

## 使用

在 Roche 的插件管理里添加下面的安装链接，启用后刷新页面：

https://raw.githubusercontent.com/zhuzeyu0424/Groche-plugins/main/wechat-albums/plugin.json?v=0.1.0

本地 ZIP 是源码备份，不能当作 CSS 粘贴。

CSS 仍在聊天室样式设置中完整替换，不需要把 JS 粘进 CSS。

## 行为

- 只把连续的本人图片消息合成一组，至少两张。
- 文字、表情包、对方消息、时间分隔会结束一组。
- 收起时保留第一张和少量叠片；展开时恢复原图片布局，不复制或修改原消息。
- 点封面仍打开原图查看；只有“展开 N / 收起”按钮控制分组。
- 原生选择消息模式下全部展示，方便选择单张。
- 插件应用“多图收起”里可关闭自动堆叠或全部收起。
- 停用、卸载后刷新 Roche，恢复逐条显示。

## 验证范围

按现有 Roche 消息类名结构，在 WebKit 上验证了 320/390/768/980px 宽度、展开/收起、原图点击、键盘操作、动态增减图片、表情包截断、选择消息、重复加载与清理。翻译也测试了新的 details-content 和旧版回退 CSS 两条路径。

尚未在你的手机当前 Roche 页面中实际安装验证；如果以后 Roche 改了消息 DOM 类名，需要适配。不会凭本地预览宣称真机验证。
