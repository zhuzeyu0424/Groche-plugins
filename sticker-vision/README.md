# 表情识别 0.1.0

Roche 独立插件。使用单独配置的视觉 API 观察双方原生表情包，在角色下一轮回复前，将描述、发送者和对应消息提供给当前聊天。

## 安装

在 Roche 插件 App 管理中安装：

https://raw.githubusercontent.com/zhuzeyu0424/Groche-plugins/main/sticker-vision/plugin.json?v=0.1.0

安装后刷新 Roche，在「表情包库 → 识别设置」打开。也可以从插件 App 打开「表情识别」。

填写独立的 API 地址、Key、视觉模型，打开「自动识别」并保存。支持 Chat Completions 兼容接口；填写站点根地址或 `/v1` 时会补全 `/v1/chat/completions`。其他路径按填写的完整接口地址调用。所选模型必须支持 `image_url` 图片输入，接口须允许 Roche 网页跨域访问。

先从「试识别一张」选择图片，再点「识别测试」验证真实接口。选择文件、保存设置本身不调用 API。没有随插件附送的 API Key。

## 使用

- 照常从原生表情面板发表情包，角色下次正常回复前识别。
- 首版接入线上单人聊天，双方的原生 `sticker` 消息都支持；不处理气泡 emoji、群聊或线下归档。
- 启用后新发送的图片会自动识别，不自动扫描历史表情库。每轮最多两张新图；读取最近 24 条消息中的最多六条表情消息。
- 图源与图片内容缓存避免重复识图；缓存最多 300 条描述，不重复存储表情原图。
- JPG、PNG、WebP 等按静态画面分析；GIF 可读取时只取一张静态画面，不能理解完整动画过程。
- 图床阻止浏览器取图时，HTTPS 静态图地址可直接交给视觉接口读取；该接口仍需要能访问图源。
- 超时、HTTP 失败和未完成尝试不自动重发。失败可在缓存页明确确认后重试，可能再次计费。
- 识别缓存支持修正描述；清缓存仅操作本插件的数据库，清后重识别可能计费。
- 图片内容只作为数据提供，人物、情绪和语气可能识别错误。角色结合聊天理解，识别失败时不宣称看懂。

## 数据

API 配置保存在当前网站的本机 localStorage；描述和尝试记录保存在独立 IndexedDB。没有上传到 GitHub 的密钥或图片，也没有修改原生表情、聊天记录或记忆。识别时图片会发送至你配置的 API。插件缓存和配置不保证包含在 Roche 原生备份中；首次换设备需重新配置。

## 验证

基于 2026-11-05 Roche 公开脚本确认异步 `contextProvider`、原生表情消息地址和表情包库结构。WebKit 自动测试覆盖图像输入、双方归属、对话隔离、内容去重、失败与重装防重发、手动重试、缓存修正与清理、弹窗层级及三种屏幕尺寸。测试使用模拟视觉接口，未调用用户付费服务；仍需在真实手机与所选视觉 API 上试用。
