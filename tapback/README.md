# 气泡贴表情 0.5.6

[安装或更新](https://raw.githubusercontent.com/zhuzeyu0424/Groche-plugins/main/tapback/plugin.json?v=0.5.6)

在 Roche「插件 App 管理」检查更新，确认版本为 0.5.6 后刷新 Roche。已有表情会自动重新定位，无需重贴。

## 本次调整

取消固定的 40px 留白。根据美化实际绘制的气泡边角放置表情，避开原文、译文、头像和相邻消息；仅在碰到上方内容时增加所需间距。支持译文独立放在气泡下方的样式。

表情宽度保持 30px，emoji 在圆形底座居中。沿用原来的左右位置，仍可点表情「换到另一边」。更换美化、字体、窗口尺寸或展开译文后重新计算位置。移除表情会撤掉对应间距。

既有表情记录、角色读取已贴表情和贴表情间隔沿用原来的设置。

## 使用

长按文字或语音气泡，在原菜单点「贴表情」。可按分类挑选，或搜索名称。点已贴的表情可以更换、换边或移除。

记录保存于当前浏览器；换设备前在插件中导出。停用或卸载后刷新 Roche。插件不额外调用 AI，不改写原消息。

使用隔离 WebKit 虚构聊天验证原生与实际 V12 美化，以及紧凑、宽气泡、无内边距、缩放和外置译文等布局。特定手机与其他自定义美化仍需真机确认。
