# 气泡贴表情 0.5.7

[安装或更新](https://raw.githubusercontent.com/zhuzeyu0424/Groche-plugins/main/tapback/plugin.json?v=0.5.7)

在 Roche「插件 App 管理」检查更新，确认版本为 0.5.7 后刷新 Roche。已有表情会自动调整，无需重贴。

## 本次调整

恢复之前的 36×44px 底座、32px 主圆和 20px emoji 比例。默认贴角位置向内收回，同时保留根据美化实际气泡边缘避开正文、译文和头像的定位。

按系统 emoji 实际图案的边界居中；超宽或被系统拆开的组合表情会缩至圆形底座安全范围。表情不再随 iOS 的文字自动放大而溢出底座。左右换边使用同一套大小和居中规则。

既有表情记录、角色读取已贴表情和贴表情间隔沿用原来的设置。

## 使用

长按文字或语音气泡，在原菜单点「贴表情」。可按分类挑选，或搜索名称。点已贴的表情可以更换、换边或移除。

记录保存于当前浏览器；换设备前在插件中导出。停用或卸载后刷新 Roche。插件不额外调用 AI，不改写原消息。

通过隔离 WebKit 验证全目录 226 个表情的实际图案边界与居中，以及原生和实际 V12 美化、长短气泡、外置译文、深色模式、滚动和窄屏布局。不同手机的系统 emoji 造型仍以真机为准。
