# 气泡贴表情 0.5.5

[安装或更新](https://raw.githubusercontent.com/zhuzeyu0424/Groche-plugins/main/tapback/plugin.json?v=0.5.5)

在 Roche「插件 App 管理」检查更新，确认版本为 0.5.5 后刷新 Roche。

## 本次调整

表情整体放在气泡外侧上角，缩小为 30px 宽，emoji 在圆形底座居中。默认沿用原来的左右位置，仍可点表情「换到另一边」。

仅对有表情的消息增加独立留白，避免遮住正文、译文、头像和上一条消息。不会修改正文或译文的内边距。移除表情时，留白同步撤掉。

支持窗口、气泡尺寸、字体和美化样式变化后重新定位。语音气泡同样适用。既有表情记录、角色读取已贴表情和贴表情间隔沿用原来的设置。

## 使用

长按文字或语音气泡，在原菜单点「贴表情」。可按分类挑选，或搜索名称。点已贴的表情可以更换、换边或移除。

记录保存于当前浏览器；换设备前在插件中导出。停用或卸载后刷新 Roche。插件不额外调用 AI，不改写原消息。

本版使用隔离 WebKit 虚构聊天验证了原生、紧凑、宽气泡、外层背景、缩放、行内文字和外置译文等布局，包括 320px 窄屏。特定手机和自定义美化仍需真机确认。
