# 亮屏守护 0.1.0

[安装地址](https://raw.githubusercontent.com/zhuzeyu0424/Groche-plugins/main/screen-awake/plugin.json?v=0.1.0)

在 Roche 的「插件 App 管理」粘贴安装地址。打开「亮屏守护」，开启「保持屏幕亮起」，看到「正在亮屏」后可回聊天页。

切换 App 或手动锁屏会释放系统亮屏锁。回到 Roche 后会重新申请。低电量模式可能限制亮屏，界面会显示拒绝或释放状态，并提供「重新申请」。

主屏幕版 Roche 需要 iOS 18.4 或更新版本。刷新 Roche 后需要重新开启开关。
